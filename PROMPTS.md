# Prompt log

This file records **every** prompt sent to the AI in this project, in the order
they were sent, together with the exact reply that came back.

The numbers here are the same numbers used in the tags in `essay.md`, so any
blue passage in the rendered essay can be traced to the request that produced it.

Rules:

- Never delete or rewrite an entry. If a prompt was a mistake, add a new entry
  saying so.
- Paste the prompt and the reply verbatim.
- One heading per prompt, in the exact form `## Prompt N`.

---

## Planning questions and answers

By Johannes's instruction, the questions the AI asked while setting the project
up — and the answers he gave — are recorded here too, in the same place as the
prompts. Nothing about how the project works should have to be guessed.

### 28 September 2026 — setting up the project

**AI question — "How should a non-technical reader see the word-level attribution?"**
Answer: A colour-coded web page plus a printable version.

**AI question — "How should we store the one master text you actually write in?"**
Answer: Markdown with light AI-only tags (only AI passages are tagged; everything
else counts as Johannes's).

**AI question — "How many categories of authorship do you want to show?"**
Answer: Two — written by Johannes, or written by the AI.

**AI question — "What should the public GitHub repo be called?"**
Answer: "Academic Skills Essay A" (published as `academic-skills-essay-a`, since
GitHub does not allow spaces in repository names).

**AI question — "What file format should the final essay be submitted in?"**
Answer: "Well, I have to hand it in as pdf, so that will be the final format.
However, how do we create an apa style pdf. Word is the most obvious choice but
I really don't like it. What other options are there?"

**AI question — "How should AI-written passages be marked inside the document?"**
Answer: "It is enough that it remains documented as we planned. It doesn't need
to be documented any further."

**AI question — "Should the document include the full prompt log, or point to the repo?"**
Answer: Just a link to the repo.

**AI question — "Which tool should generate the final APA PDF?"**
Answer: "if typst handles references then that." (Typst does, so Typst it is.)
